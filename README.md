# shadcn/ui

> **About this fork:** This is Ryan's upstream-tracking fork of [shadcn/ui](https://github.com/shadcn-ui/ui), not the cross-project component package. The reusable application components, themes, and compositions live in [interface-system](https://github.com/ryanwhois/interface-system). See [FORK_MAINTENANCE.md](./FORK_MAINTENANCE.md) for safe upstream sync and where customisations belong.

A set of beautifully designed components that you can customize, extend, and build on. Start here then make it your own. Open Source. Open Code. **Use this to build your own component library**.
