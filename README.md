## This Fork: Update Policy

This repository is an upstream-compatible fork of [shadcn-ui/ui](https://github.com/shadcn-ui/ui), **not** the published `@ryanwhois/interface-system` React package. Keep the fork close to upstream; put project-neutral compositions, themes, reusable application controls, and consumer-facing releases in [interface-system](https://github.com/ryanwhois/interface-system).

See [Fork Maintenance](./docs/FORK_MAINTENANCE.md) for the update process, conflict policy, provenance rules and how to propagate adopted components into the shared package. Upstream release/registry workflows may be restricted to `shadcn-ui/ui` and should not be assumed to run on this fork.
